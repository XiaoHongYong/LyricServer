Display Lyrics with MediaMonkey

MiniLyrics is a lyrics plugin software for MediaMonkey. It can download and display lyrics automatically.

Run MiniLyrics with MediaMonkey

When you start MediaMonkey, MiniLyrics will run with it automatically.

Embed MiniLyrics in MediaMonkey Window.

MiniLyrics can be embedded as a panel in MediaMonkey Window, please follow the instructions below:

  1. Download and install 'Embedded MiniLyrics' plugin from MediaMonkey Forum.
    http://www.mediamonkey.com/forum/viewtopic.php?t=9679
  2. If MiniLyrics panel isn't embedded in MediaMonkey Window, please click MediaMonkey menu item: 'View' > 'MiniLyrics Panel'.
  3. If it's a blank white window in MiniLyrics panel, please use 'Plain' skin of MiniLyrics.
  4. If you got some other errors, please download this file.
    • Extract the downloaded file.
    • Open folder: C:\Program Files\MediaMonkey\Scripts\Auto
    • Remove file: MMEmbedder.dll
    • Replace file: MiniLyrics Embedder.vbs
