{% layout = "minilyrics/faq/base.html" %} {-title-}How do I save, load and remove embedded lyrics in song file?{-title-} {-sub_content-}

MiniLyrics supports embedded lyrics in MP3 and M4A files.

You could view embedded lyrics in iTunes, iPod, iPad and Windows Media Player.

  • ID3v2 synchronized lyrics, ID3v2 unsynchronized lyrics and Lyrics3v2 lyrics are for MP3 files.
  • M4A lyrics are for apple M4A(AAC) files.

How do I save embedded lyrics?

  1. Please click context menu item
  2. Then click 'Lyrics' -> 'Save Lyrics in Song File'.
  3. In the popup dialog, choose the embedded lyrics format to save.
  4. Then click OK.

How do I load embedded lyrics?

  1. Please click context menu item
  2. Then click 'Search Lyrics'.
  3. Select Embedded lyrics for iPod, iTunes...
  4. In the popup dialog, then click 'More >>'. If there hasn't Embedded lyrics in list , no embedded lyrics is in the song file.

How do I remove embedded lyrics?

  1. Please click context menu item
  2. Then click 'Search Lyrics'.
  3. In the popup dialog, choose the embedded lyrics.
  4. Then click 'More >>'.
  5. Then click 'Delete File' menu item to delete the lyrics. If there hasn't Embedded lyrics in list , no embedded lyrics is in the song file.
