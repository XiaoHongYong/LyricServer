{% layout = "minilyrics/faq/base.html" %} {-title-}View Lyrics in Windows Media Player, iTunes, or on iPod{-title-} {-sub_content-}

Save Lyrics in song files with MiniLyrics.

  1. On the context menu, point to Lyrics, and then click Save Lyrics in song File.
  2. Check Embedded lyrics for iTunes, iPod (ID3v2 unsynchronized lyrics)), and then click OK.

View Lyrics in iTunes.

  1. Select the song file in iTunes.
  2. Click the File menu, and then click Get Info.
  3. Click lyrics tab in the popup dialog. The lyrics will be displayed in the dialog.

View Lyrics on iPod.

  1. A simple solution is to use Lyrics downloader for iPod to download lyrics.
  2. After save lyrics in media files, plugin your iPod to sync your media library.
