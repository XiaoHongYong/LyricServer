Installation Problems

'Error Opening file for writing'

  • If you got this error message below, please close your player or restart your computer, then try to install MiniLyrics again.
  • If this problem still can't be resolved, please uninstall MiniLyrics, then restart your computer, and install MiniLyrics again.
