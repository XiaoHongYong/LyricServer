Other Players

MiniLyrics is a lyrics plugin software for Foobar2000, Songbird, AIMP2, The KMPlayer, J. River Media Center, J. River Media Jukebox, Quintessential Player, BSPlayer, Silverjuke. It can download and display lyrics automatically.

Run MiniLyrics

When you start Foobar2000, Songbird, AIMP2, The KMPlayer, J. River Media Center, J. River Media Jukebox, Quintessential Player, BSPlayer, Silverjuke, MiniLyrics will start with them automatically.
