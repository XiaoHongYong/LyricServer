How do I solve internet connection errors?

  1. Make sure your PC is connected to Internet.
  2. Click here to check if our server is OK.
  3. Check if you have firewall installed. If You are under the Firewall, you will be warned of the following messages:
    10057, A request to send or receive data was disallowed because ...
    10013, An attempt was made to access a socket in a way forbidden ...
    10061, No connection could be made because the target machine actively refused it.
    ...
    You will need to allow MiniLyrics.exe to access internet. Here's the detailed instructions for windows firewall settings.
    MiniLyrics can be located at: c:\Program files\MiniLyrics\MiniLyrics.exe
  4. If you are using proxy, please make sure MiniLyrics' proxy setting is correct.
