Display Lyrics with XMPlay

MiniLyrics is a lyrics plugin software for XMPlay. It can download and display lyrics automatically.

Run MiniLyrics with XMPlay

You need to configure MiniLyrics in XMPlay Options.

  1. Please click the context menu item 'Options and stuff' of XMPlay
  2. Then click 'DSP' item in the popup window
  3. Next add DSP plug-in 'MiniLyrics for XMPlay'.

When you start XMPlay, MiniLyrics will run with it automatically.
