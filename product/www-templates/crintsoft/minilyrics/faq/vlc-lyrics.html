Display Lyrics with VLC Media Player

MiniLyrics is a lyrics plugin software for VLC Media Player. It can download and display lyrics automatically.

Setup MiniLyrics

You need to configure MiniLyrics in VLC Media Player Preferences.

  1. Only VLC 32 bit for windows is supported.
  2. Click VLC menu item: 'Tools' > 'Preferences'.
  3. In the popup window, show all settings, and open control interface, then check 'MiniLyrics-Auto display lyrics....'.

  4. Restart your VLC player, and MiniLyrics will auto start with VLC now.
