Other Players

MiniLyrics is a lyrics plugin for:

  • Spotify
  • Zune
  • Album Player
  • Helium Music Manager
  • JetAudio
  • Media Player Class Home Cinema

It can download and display lyrics automatically.

Run MiniLyrics

When you start Spotify, Zune, Album Player, Helium Music Manager, JetAudio, MiniLyrics won't run with it, you need to click Windows 'Start' menu button, then click 'All program files' > 'MiniLyrics' > 'MiniLyrics' to run MiniLyrics.
