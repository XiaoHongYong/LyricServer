MiniLyrics supports embedded lyrics in MP3 and M4A files.

MiniLyrics supports to save and load embedded lyrics in MP3 and M4A files.

  • ID3v2 synchronized lyrics, ID3v2 unsynchronized lyrics and Lyrics3v2 lyrics are for MP3 files.
  • M4A lyrics are for apple M4A(AAC) files.

ID3v2 unsynchronized lyrics

iPod, iPad, iTunes, Windows Media Player, MediaMonkey, and many other players support ID3v2 unsynchronized lyrics.It's defined in ID3v2 specification.

ID3v2 synchronized lyrics

Only Windows Media Player supports ID3v2 synchronized lyrics. It's defined in ID3v2 specification.

Lyrics3v2 synchronized lyrics

It is an old specification, only MiniLyrics supports this format. It's defined in Lyrics3v2.00 specification.
