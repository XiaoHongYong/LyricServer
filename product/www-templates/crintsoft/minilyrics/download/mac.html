Installation instructions

MiniLyrics is a lyrics plugin for iTunes.

  1. Download MiniLyrics
  2. Install MiniLyrics.pkg
  3. Run MiniLyrics from Application folder.
  4. You will be asked to install MiniLyrics plugin for iTunes, click YES.
  5. Start iTunes, and play a few tracks, MiniLyrics will display lyrics.
