_TLM(How do I use the Lyrics Editor to create LRC lyrics?)

_TLM(Lyrics Editor will help you to create or edit the synchronized lyrics.)

  1. _TLM(Get plain text lyrics. You can search and download text lyrics with MiniLyrics or Google.)
  2. _TLM(Open the plain text lyrics file.)
  3. _TLM(Open 'Lyrics Editor'. Please click the context menu item: 'Lyrics Editor', and MiniLyrics will open the 'Lyrics Editor' window.)
  4. _TLM(Playing the song file.)
  5. _TLM(Click button: )"_TLM(Synchronize the current line and move down one line).
  6. _TLM(Repeat step 5 until all the lyrics lines are synchronized.)
  7. _TLM(Save the lyrics file as '.lrc' file.)

_TLM(Windows Media Player, foobar2000 is suggested to be used, when you create synchronized lyrics. If you use Winamp, please don't seek or jump music, or the timeline will become imprecise.)

_TLM(Share lyrics with other people using MiniLyrics)

_TLM(You can upload the lyrics to MiniLyrics server.)

  • _TLM(Clicking menu item: 'File' -> 'Upload Lyrics' -> 'Upload Lyrics'.)
  • _TLM(Then follow the instructions in the popup window.)
  • _TLM(If you don't have account, please sign up free.)
