Show lyrics in Windows Media Player or Windows Media Center Visualization area?

  1. Click right mouse button on Windows Media Player, make sure 'MiniLyrics Plugin for WMP' menu item in is NOT checked as the screen shot below.
  2. Switch to Windows Media Player 'Now Playing' view as below.
  3. Then check MiniLyrics menu item in the context menu item of Windows Media Player Visualization area.
    Then you will see MiniLyrics embedded in Windows Media Player, see screen shot below.
