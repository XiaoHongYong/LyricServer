Display Lyrics with Windows Media Player

MiniLyrics is a lyrics plugin software for Windows Media Player. It can download and display lyrics automatically.

Run MiniLyrics with Windows Media Player

When you start Windows Media Player, MiniLyrics will run with it automatically.

MiniLyrics can be embedded in Windows Media Player window
