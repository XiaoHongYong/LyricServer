MiniLyrics is a lyrics plugin software for iTunes

  • It can download and display lyrics automatically.
  • Save ID3v2 unsynchronized lyrics in song file, so you can view it in iTunes, iPod touch.

Run MiniLyrics with iTunes

When you start iTunes, MiniLyrics will run with it automatically.

Embed MiniLyrics in iTunes Window.

MiniLyrics can be embedded in iTunes window.

  1. Click iTunes menu item: 'View' > 'Visualizer' > 'MiniLyrics Visualizer', set MiniLyrics as default visualizer.
  2. Click iTunes menu item: 'View' > 'Show Visualizer', then MiniLyrics will be embedded in iTunes window as below.
